# Проект крестики-нолики (серверная часть)

Серверная часть игры "Крестики-нолики" с поддержкой многопользовательского режима и игры против компьютера. Реализована на Go с использованием PostgreSQL в качестве хранилища данных.

## Запуск приложения

### Настройка базы данных

Для корректной работы с базой данных необходимо создать базу данных PostgreSQL cо следующими параметрами

```
Host: "localhost"
Port: "5432"
User: "postgres"
Password: "postgres"
Database: "tictactoe"
```

Для упрощения настройки а ходе проверки используются стандартные настройки подключения к БД. Таблицы создаются автоматически при первом запуске.

### Запуск сервера напрямую

Из папки src

`go run cmd/tic-tac-toe/main.go`

Сервер будет доступен по адресу: `http://localhost:8080`

### Запуск сервера с помощью Docker

Из папки src

`docker compose up --build`

Сервер будет доступен по адресу: `http://localhost:8080`

## Api Endpoints

### Регистрация пользователя

Авторизация не требуется.

`POST http://localhost:8080/api/auth/register`
Тело запроса должно включать в себя JSON вида

```
{
"username": "test_username"
"password": "test_password"
}
```

Ограничения:

- длина логина 50 символов.
- на длину пароля 255 символов.
- Логин должен быть уникальным.
- Пароль и логин не должны быть пустыми.

### Авторизация

Аутентификация пользователя с использованием Basic Auth. Авторизация не требуется.

`POST http://localhost:8080/api/auth/login` <br>
`Authorization: Basic <base64(login:password)>`

## Игры

Все эндпоинты игр требуют авторизации. Заголовок Authorization: Basic <base64> должен присутствовать в каждом запросе.

### Создание новой игры

Создает новую игровую сессию.

`POST http://localhost:8080/api/games`

Тело запроса для игры с компьютером:

```
{
    "game_type": "vs_computer"
}
```

или игры с другим игроком

```
{
    "game_type":"vs_player"
}
```

Игра с компьютером готова к игре сразу, игра с человеком находится в статусе ожидания второго игрока.

### Получение списка доступных игр

Возвращает список игр, ожидающих второго игрока. Игры, созданные текущим пользователем, исключаются из списка.

`GET http://localhost:8080/api/games/available`

### Присоединение к игре

`POST http://localhost:8080/api/games/{id}/join`

### Получение состояния игры

Возвращает текущее состояние игровой сессии.

`GET http://localhost:8080/api/games/{id}`

### Совершение хода

`POST http://localhost:8080/api/games/{id}/move`

Тело запроса должно включать в себя JSON вида

```
{
"Row": 0
"Col": 0
}
```

id - должно существовать. <br>
Row и Col - должны быть числами от 0 до 2.<br>
Ячейка не должна быть занята.<br>

Игра продолжается до победы одного из игроков или пока не закончатся пустые ячейки.

## Пользователи

Все эндпоинты пользователей требуют авторизации.

### Получение списка пользователей

Возвращает список всех зарегистрированных пользователей

`GET http://localhost:8080/api/users`

### Получение информации о пользователе

`GET http://localhost:8080/api/users/{id}`
